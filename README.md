# Sinta's little universe 💜
A responsive, interactive My Girl Day page for Sinta Rahmawati, from Allief.

## Run locally
```sh
python3 -m http.server 3000
```
Open http://localhost:3000. No build step or dependencies required.

## Vercel
Import `allifiz/mygirl`, choose framework **Other**, leave build command empty, and output directory `.`. The included `vercel.json` configures static hosting.

## Features
Personal letter, reversible message cards, five-heart mini game, virtual hugs, heart bursts, optional original synthesized melody, keyboard controls and reduced-motion support. Music starts only after a click. No tracking, forms or personal-data collection.

Edit text in `index.html`, colors in `style.css`, and interactions in `script.js`.
